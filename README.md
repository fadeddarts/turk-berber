# Wilson Hair Saloon & Türk Berber

Standalone site for Wilson Hair Saloon & Türk Berber, 893 Wilson Ave, North York. It does not share layouts, colour, type, or photography with the Natural Barber Shop, New Relook, or Social Club projects.

```bash
npm install
npm run dev
```

The dev server uses port 5177.

Verified facts live in `src/data/`. Service names and prices, remaining weekly hours, Facebook’s direct URL, and barber biographies beyond the Google review of Ziya are marked as placeholders.

Photographs in `public/images/` are editorial stand-ins, not pictures of the shop or of Ziya. Replace them with the shop’s own photography before launch.
